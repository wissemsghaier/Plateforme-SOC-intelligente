POST LINKEDIN - VERSION PROFESSIONNELLE (FOCUS MACHINE LEARNING)

Titre:
De la détection à la réponse automatique: mon SOC intelligent basé sur le Machine Learning

Texte:
J’ai conçu et implémenté une plateforme SOC intelligente qui connecte la détection, l’enrichissement et la réponse automatique dans un workflow unifié.

Objectif principal:
Réduire le temps de réaction incident en combinant SIEM + SOAR + Machine Learning.

Architecture mise en oeuvre:
- Wazuh pour la collecte et la détection
- MISP et Cortex pour l’enrichissement Threat Intelligence
- Pipeline ML pour le scoring/priorisation des alertes
- Shuffle pour l’orchestration SOAR
- API de réponse pour les actions automatiques Linux/Windows
- TheHive pour la traçabilité et la gestion opérationnelle

Ce que le Machine Learning apporte concrètement:
1) Priorisation intelligente des alertes
   - Met l’accent sur les événements à plus fort risque
   - Réduit le bruit opérationnel pour les analystes

2) Aide à la décision SOC
   - Support de triage orienté criticité
   - Meilleure allocation du temps analyste

3) Réduction du temps de réponse
   - Détection -> scoring -> décision -> action automatique
   - MTTR réduit sur les cas critiques

4) Standardisation des réponses
   - Règles de déclenchement maîtrisées
   - Traçabilité complète des actions exécutées

Résultat:
Une chaîne end-to-end opérationnelle:
Detection -> Enrichment -> ML Scoring -> Automated Response -> TheHive Traceability

Compétences démontrées:
Cybersecurity, SOC, SIEM, SOAR, Machine Learning, Python, Docker, API Integration, Incident Response.

Conclusion:
Ce projet illustre la transition d’un SOC "alert-centric" vers un SOC "action-centric" piloté par la donnée, avec une réponse plus rapide, plus cohérente et auditable.
